# Decision Support System for Inventory Management (СППР Управления Запасами)

Система поддержки принятия решений (СППР) для управления товарно-материальными запасами, оптимизации закупок, многокритериальной оценки поставщиков и предиктивной аналитики спроса в условиях неопределенности.

## Архитектура системы

СППР построена на принципах чистой предметно-ориентированной архитектуры (Domain-Driven Design) и включает следующие ключевые подсистемы:

1. **Онтология и база знаний (`inventory_dss.knowledge`)**:
   - Формальная онтология сущностей, связей и аксиом управления запасами.
   - Продукционный движок логического вывода (forward chaining) с разрешением конфликтов (salience, specificity, refraction) и объяснением решений (Explainable DSS).
2. **Типизированные контракты предметной области (`inventory_dss.models`)**:
   - Строгие Pydantic v2 схемы данных: SKU, Поставщики, Склад, Динамика спроса, Состояния запасов с вычислением эффективного остатка $I_{eff}$, Прогнозы, Планы оптимизации, Рекомендации и Заказы.
3. **Генерация данных (`inventory_dss.data`)**:
   - Синтетический воспроизводимый генератор (seed=42) номенклатуры (25 SKU, 4 категории), 730 дней истории спроса с сезонностью, трендами, промо-всплесками и прерывистым спросом (Croston), карточек 5 поставщиков и параметров склада.
4. **Оценка поставщиков (`inventory_dss.suppliers`)**:
   - Многокритериальный анализ (MCDA): метод анализа иерархий (AHP Саати с проверкой $CR < 0.10$), энтропия Шеннона, метод TOPSIS и дерево решений для оценки рисков срыва поставок.
5. **Прогнозирование спроса (`inventory_dss.forecasting`)**:
   - Точечные и интервальные прогнозы (95% доверительные коридоры) на базе экспоненциального сглаживания Хольта-Винтерса, регрессионных моделей с лагами и метода Кростона для редкого спроса.
6. **Оптимизация запасов (`inventory_dss.optimization`)**:
   - Стохастический расчет страхового запаса $SS$ и точки заказа $ROP$ при совместной неопределенности спроса и сроков поставки ($SS = Z_\alpha \sqrt{\mu_L \sigma_D^2 + \mu_D^2 \sigma_L^2}$).
   - Оптимальный размер партии (EOQ) с учетом многономенклатурных ограничений вместимости склада ($V_{max}$, $W_{max}$) через условия Куна-Таккера (KKT).
7. **Интерактивный BI-интерфейс (`inventory_dss.ui`)**:
   - Реактивный дашборд на Streamlit и Plotly с 5 экранами: сводка KPI, матрица ABC/XYZ, предиктивная аналитика спроса, радар поставщиков и рабочее место ЛПР (Decision Workbench) с What-If симуляцией.
8. **Паспорт СППР (`docs/PASSPORT_DSS.md`)**:
   - Полное структурированное отражение 8 канонических разделов по методологической цепочке: *Постановка $\to$ Метод $\to$ Результат $\to$ Интерпретация*.

## Быстрый старт

Проект использует современный инструментарий `uv` для управления окружением и зависимостями:

```bash
# Проверка зависимостей и запуск тестов
uv run pytest tests/unit/test_models.py tests/unit/test_knowledge.py -v

# Запуск полного набора тестов
uv run pytest -v
```

## Структура проекта

```
inventory_dss/
├── pyproject.toml              # Конфигурация сборки и зависимости (uv)
├── README.md                   # Руководство и описание проекта
├── specs/
│   └── 001-inventory-dss/
│       ├── spec.md             # Полная спецификация /speckit-specify
│       └── checklists/
│           └── requirements.md # Валидационный чек-лист спецификации
├── docs/
│   └── PASSPORT_DSS.md         # Паспорт СППР (8 разделов по шаблону Google Docs)
├── src/
│   └── inventory_dss/
│       ├── __init__.py
│       ├── config.py           # Конфигурационные константы и параметры
│       ├── models/
│       │   ├── __init__.py
│       │   └── domain.py       # Pydantic v2 схемы предметной области
│       ├── knowledge/
│       │   ├── __init__.py
│       │   ├── ontology.py     # Онтология предметной области DSS
│       │   └── rules.py        # Продукционный движок правил прямого вывода
│       ├── data/               # Генератор синтетических данных (M2)
│       ├── suppliers/          # Оценка поставщиков AHP/TOPSIS (M2)
│       ├── forecasting/        # Прогнозирование спроса и неопределенности (M3)
│       ├── optimization/       # Оптимизация EOQ, SS, ROP, KKT (M3)
│       ├── recommendations/    # Рекомендательный модуль (M4)
│       └── ui/                 # Streamlit BI дашборд (M4)
└── tests/
    ├── conftest.py             # Фикстуры pytest
    └── unit/
        ├── test_models.py      # Тесты моделей Pydantic v2
        └── test_knowledge.py   # Тесты онтологии и движка правил
```
